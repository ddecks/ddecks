## AWS Solutions Architect Associate — Done

I passed the AWS Solutions Architect Associate (SAA-C03) exam. Working with AWS products daily made a lot of the material familiar, but the exam still had its share of curveballs — especially around edge cases with service integrations and cost optimization tradeoffs.

The biggest help was [cert-drill]({{% relref "cert-drill" %}}), the CLI tool I built specifically for this. Being able to capture my reasoning alongside each answer, then have AI review my thought process, caught misconceptions I didn't know I had. Things like confusing DAX caching scope or mixing up FSx variants.

## What's Next: AWS Machine Learning Associate (MLA-C01)

Now I'm preparing for the AWS Certified Machine Learning Engineer - Associate (MLA-C01). This one covers:

- Building ML solutions with SageMaker
- Data engineering for ML pipelines
- Model deployment and monitoring
- MLOps and automation

It's a different beast from SAA. Less about "which service fits this architecture" and more about understanding the ML lifecycle end-to-end on AWS — from data prep through model serving.

I'm using the same study approach: practice questions with cert-drill, reasoning capture, and AI-assisted review. The structured export format has been especially useful for ML topics where the reasoning chains are longer and more nuanced.
